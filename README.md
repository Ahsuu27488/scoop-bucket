# Scoop bucket

[Scoop](https://scoop.sh) apps by Muhammad Ahsan.

```powershell
scoop bucket add ahsuu27488 https://github.com/Ahsuu27488/scoop-bucket
scoop install ahsuu27488/taskvane
```

| App | What it is |
|---|---|
| [Taskvane](https://taskvane.ahsandev.site) | A better Task Manager for Windows 11, with CPU and GPU temperatures, power draw and battery health |

Taskvane installs the portable build; its settings are kept across updates.
